# 高中数学专题文档生成与数学问题解决

面向"刚学完必修课、基础较弱"的学生。所有数学内容须与**人教版A版教材**对齐，讲清来龙去脉，难度循序渐进，且必须保证每一步数学推导正确。

## 一、专题 Word 文档生成（.docx）

### 标准文档结构
```
标题页
├─ 知识梳理
│   ├─ 知识网络（层级树：类别 → 条目）
│   ├─ 核心概念精讲（从定义讲起，逐条展开）
│   ├─ 重要公式一览（表格：名称|公式|说明）
│   ├─ 常见误区辨析（⚠常见错误 + ✓正确理解）
│   └─ 重点提示
└─ 每个专题（按教材章节拆分）
    └─ 每个考点
        ├─ 正文讲解
        ├─ 例题 1 道（完整步骤）
        ├─ 实战 5 道（带难度星级 + 答案）
        └─ 每专题末尾 1 个拓展（选学/背景知识）
```

### 内容规范
- 概念从定义讲起，例题有逐步解答（标 ① ② ③），答案含推导过程。
- 实战难度用星级：★☆☆ 基础 / ★★☆ 中等 / ★★★ 拔高，每题都附答案。
- 例题编号全文档连续（【例题1】~【例题N】），考点按专题顺序编号，每考点=1例题+5实战。
- 几何题优先用正方体/长方体/坐标法（数字简单、可建系），降低计算量。
- 生成后必须校验：例题编号连续、每考点实战数=5、答案齐全、无公式错漏。

## 二、数学建模

按标准流程，最终常产出建模论文（LaTeX 或 docx）：
1. **问题重述**：用自己的话复述，提炼目标。
2. **模型假设**：明确列出，条条可检验，说明合理性。
3. **符号说明**：表格化（符号 | 含义 | 单位）。
4. **模型建立**：给出数学表达式/算法框架，说明依据。
5. **模型求解**：解析推导或数值求解（推荐 Python：numpy/scipy/sympy/pandas/matplotlib）。
6. **结果分析**：代入数据检验、灵敏度分析、误差讨论。
7. **模型评价**：优点、局限、改进方向。
8. 若要求提交代码：附可运行脚本（含注释、不泄漏密钥），输出图表存 PNG。

## 三、LaTeX 生成规范

### 中文数学文档
```latex
\documentclass[12pt]{ctexart}
\usepackage{amsmath, amssymb, amsthm}
\usepackage{geometry, graphicx, booktabs}
\geometry{a4paper, margin=2.5cm}
```
- 中文正文用 ctex 系（ctexart/ctexbook）；行内公式 `$...$`，独立公式 `\[...\]`、`equation`、`align`。
- 定理/例题用 `\newtheorem`；表格用 `booktabs`；图形用 tikz 或插入 PNG。

### 公式风格
- 行内 `$x_1^2$`；多行用 `align` 对齐；分数 `\frac{a}{b}`；根式 `\sqrt{}`；希腊字母 `\alpha,\theta,\lambda,\pi`。
- 向量 `\vec{a}` 或 `\mathbf{a}`；集合 `\in,\subseteq,\cap,\cup`；逻辑 `\iff,\Rightarrow`。
- 完成后编译验证（TeX Live 等），确保无编译错误。

## 四、数学问题解答

- 先明确已知与所求，必要时画图；按"设未知数→列方程/关系→求解→检验→规范作答"组织。
- 步骤编号清晰（① ② ③），关键公式单独成行，最终答案用"答：..."结尾。
- 计算后复核：代入原题检验、检查单位与符号（负数、无解、增根）。
- 涉及高考考点时点明方法（坐标法、待定系数法、设而不求等），并提示易错点。

## 五、数学正确性保障（务必执行）

数学内容容错率低，任何数值错误都会损害可信度。生成含数值的题解时：
1. **逐题验算**：解完方程后代入回代确认；三角形/几何题检查边长是否满足三角不等式。
2. **公式核对**：对照教材/权威来源确认公式形式（如椭圆 a²=b²+c²，双曲线 c²=a²+b²）。
3. **慎用记忆值**：不确定的数值（如某年高考真题的系数）必须显式推导或标注"示例值"。
4. **建模结果检验**：结果代入模型应自洽，量纲一致；数值解与解析解互相印证。
5. 若一处算错，检查同文档内依赖它的所有后续结果是否需连带修正。

## 六、公式的跨媒介表示对照

同一公式在不同输出媒介中的写法（AI 需按目标媒介切换）：
| 媒介 | 示例 |
|---|---|
| Markdown | `$\frac{-b\pm\sqrt{b^2-4ac}}{2a}$` |
| LaTeX | `\frac{-b\pm\sqrt{b^2-4ac}}{2a}` |
| Word 文本(Unicode) | (−b±√(b²−4ac))/(2a) |
| 纯文本 | (-b±sqrt(b^2-4ac))/(2a) |

## 七、交付前检查清单

- [ ] 数学推导正确、数值已验算
- [ ] 与教材定义一致、不超纲（面向基础学生）
- [ ] 文档结构完整（标题/知识梳理/专题/考点/例题/实战/答案/拓展）
- [ ] 例题编号连续、实战数量符合要求、答案齐全
- [ ] 中文排版正确（docx 用宋体/黑体，LaTeX 用 ctex）
- [ ] 若含代码：可运行、无密钥、有注释
