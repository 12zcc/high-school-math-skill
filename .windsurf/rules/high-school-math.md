# 高中数学专题文档与数学问题规范

完整规范见仓库根 `AGENTS.md`。以下是快速要点：

## 文档生成（.docx）
结构：标题页 → 知识梳理（知识网络/概念精讲/公式表/误区辨析/重点提示）→ 专题 → 考点（讲解 + 例题1道 + 实战5道带星级★☆☆/★★☆/★★★及答案）→ 每专题1个拓展。例题编号连续，每考点=1例题+5实战，生成后校验编号与答案。

## 数学建模（论文对齐 CUMCM 官方格式）
摘要(≤1页，含模型+方法+关键数值结论) → 关键词(3~5) → 问题重述 → 问题分析 → 模型假设 → 符号说明 → 模型建立与求解 → 模型检验(误差/灵敏度) → 模型评价与推广 → 参考文献(GB/T 7714) → 附录(可运行代码+PNG)。公式/图表编号并正文引用；求解用 Python（numpy/scipy/sympy/matplotlib）；书面化、忌口语化。

## 数学正确性
- 每题验算：代入回代、三角不等式、量纲一致。
- 公式对照教材：椭圆 a²=b²+c²，双曲线 c²=a²+b²，抛物线 y²=2px 焦点 (p/2,0)。
- 不确定数值显式推导或标注"示例值"。

## LaTeX
中文用 ctexart + amsmath/amssymb/geometry/booktabs；公式 `align` 对齐；tikz 画图；完成后编译验证。
